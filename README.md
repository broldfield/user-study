# User Study Code

This is a code repository for the `No Single Lens on Uncertainty: How Decision-Makers Vary in Their Use of Uncertainty in Environmental Maps` paper.

## Code

The code is broken into two sections:

- heatmap
- prefmod

Both are written in R.

## Data

Both code examples assume access to the source dataset. Due to ethic guidelines, the source dataset cannot be released in full as it contains sensitive data. Anonymised Data may be released upon request for data columns where this is reasonable.
